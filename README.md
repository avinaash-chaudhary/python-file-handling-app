# FileForge

A simple file handling app built with Python and Streamlit. It supports CRUD operations: create, read, update (rename/append/overwrite) and delete text files from the browser.

## Features
- Create, read, update and delete files
- Simple web UI with Streamlit
- Terminal version also included (`filehandling.py`)

## Tech Stack
Python, Streamlit

## How to run
```
pip install streamlit
streamlit run app.py
```

For the terminal version:
```
python filehandling.py
```
